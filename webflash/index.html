Installation USB

  1. Ouvre cette page dans Chrome ou Edge sur ordinateur.
  2. Branche l'ESP32 en USB (bouton BOOT appuyé pendant le branchement si la connexion échoue).
  3. Clique sur le bouton ci-dessous, choisis le port de l'ESP32, puis « Install ».

Important : si on te propose « Erase device », laisse la case décochée. Le Wi-Fi et l'appairage Bluetooth sont alors conservés.

Mise à jour depuis une version 2.x ou antérieure : la version 3 change la table de partitions (pour les mises à jour sans fil). Les réglages MQTT sont perdus une seule fois : au redémarrage, connecte-toi au réseau Wi-Fi Edilkamin_BT_AP et ressaisis le Wi-Fi et le MQTT.

Mises à jour suivantes (sans câble)

Télécharge firmware.bin, puis ouvre http://<adresse-IP-de-l'ESP>/update (utilisateur admin, mot de passe = ton mot de passe MQTT, ou edilkamin s'il est vide).

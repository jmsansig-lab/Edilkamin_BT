# Edilkamin BT Bridge

Pilotage local d'un poêle Edilkamin « The Mind » depuis Home Assistant, en Bluetooth, sans cloud (ESP32 + MQTT).

Basé sur [netmb/Edilkamin_BT](https://github.com/netmb/Edilkamin_BT).

- **Installation :** https://jmsansig-lab.github.io/Edilkamin_BT/
- **Mise à jour sans câble :** `http://<IP-de-l-ESP>/update`
- **Détails :** [guide complet](docs/GUIDE.md) · [registres](docs/registers.md)
